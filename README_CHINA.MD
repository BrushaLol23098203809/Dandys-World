## 丹迪的世界 3D 模拟器

这就是丹迪的世界 3D 模拟器，一款 3D 冒险游戏。

## 如何玩丹迪的世界模拟器？

游戏目标：你和你的团队必须探索花园景博物馆和教育中心的各个楼层。你需要在限时小游戏中完成任务来提取“Eor”，并装满提取器才能进入下一层。

可玩角色：超过 3D 个独特的角色可供选择和解锁。每个角色都有不同的属性、技能和玩法。

饰品和道具：你可以装备饰品来定制角色的技能，并在丹迪的商店购买有用的道具（例如速度提升道具）来生存。

## 游戏背景故事

在色彩缤纷的外表下，这款游戏隐藏着一个深刻而黑暗的故事。花园景中心曾是一个教育中心，也是一部从1990年到2002年播出的热门儿童电视节目的拍摄地。节目中那些友善的角色，或者说“卡通人物”，最初是用一种名为“伊科尔”（Ichor）的黑色墨水状物质赋予生命的。2002年，由于一场悲剧性的“故障事故”，该中心被迫关闭。如今，废弃的大厅里游荡着“扭曲者”——那些被腐化成怪物的原始卡通人物。
